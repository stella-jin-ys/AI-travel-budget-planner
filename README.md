# AI Travel Budget Planner

AI Travel Budget Planner creates a feasible, itemized trip plan for solo travelers, college students, short family holidays, and short ski trips.

The planner combines transport, accommodation, activities, local travel, food, source freshness, warnings, and budget calculations in one Prism Ledger workspace.

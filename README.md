# AI Travel Budget Planner

AI Travel Budget Planner creates a feasible, itemized trip plan for solo travelers, college students, short family holidays, and short ski trips.

The planner combines transport, accommodation, activities, local travel, food, source freshness, warnings, and budget calculations in one Prism Ledger workspace.

## Live app

[Open AI Travel Budget Planner](https://stella-jin-ys.github.io/AI-travel-budget-planner/)

## Run locally

```bash
cd travel-planner
npm install
npm run dev
```

## Verify

```bash
npm test
npm run test:e2e
npm run typecheck
npm run lint
npm run build
```

## Current scope

This release is a deterministic Switzerland family-trip demo. Prices, schedules, and supplier links are synthetic estimates for demonstration; it does not process bookings or payments or call live travel providers.
